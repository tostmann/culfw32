Quick-Presets:
Hex format depends on the protocol — same scheme as the ASCII frontend F<hex> / Z<hex> / A<hex> / K<hex> / E<hex>:
  • FS20: 4–8 bytes (housecode 2 + addr 1 + cmd 1 [+ extension])
  • KS300: 1–12 bytes
  • EM: exactly 9 bytes, otherwise LENERR
  • Moritz / AskSin: the first byte is the length, then the payload (= length bytes)
  • FastRf: raw bytes (the CC1101 adds the length byte itself)
